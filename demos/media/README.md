# Plain web S3 + imgproxy demo

See [setup, HTTP contract and regression instructions](../../docs/media-integrations.md). Run the loopback media host and `npm run dev`, then open `/demos/media/` on port 13700.

Upload a supported image, set focus, reuse the original, preview three server crops, save/restore a snapshot and explicitly publish responsive HTML. Credentials stay server-side; this local host is not a production authentication service.
